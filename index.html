📌 O tej stronie - Roblox Info Hub

Roblox Info Hub to zaawansowana wyszukiwarka informacji o użytkownikach platformy Roblox. Strona korzysta z oficjalnego API Roblox, aby dostarczyć jak najwięcej publicznie dostępnych danych.

🔹 Co można znaleźć? - Pełny profil użytkownika (nazwa, ID, data utworzenia, opis, status konta), listę wszystkich publicznych gier stworzonych przez użytkownika, listę grup do których należy użytkownik wraz z rolami i rangami, awatar użytkownika oraz odznaki (badges).

🔹 Jak wyszukiwać? - Możesz wyszukać użytkownika po nazwie (np. "oskar90193", "Roblox", "Builderman") lub po numerze ID konta. Po wpisaniu nazwy strona automatycznie znajdzie ID i pobierze wszystkie dane.

🔹 Dlaczego warto? - To najprostszy sposób aby sprawdzić szczegółowe informacje o dowolnym użytkowniku Roblox bez logowania się na platformę. Wszystkie dane pochodzą bezpośrednio z API Roblox i są na bieżąco aktualizowane.

🔹 Techniczne szczegóły - Strona używa endpointów API: users.roblox.com (dane użytkownika), games.roblox.com (gry użytkownika), groups.roblox.com (grupy użytkownika) oraz thumbnails.roblox.com (awatar). Ze względu na ograniczenia CORS używamy proxy api.allorigins.win.
